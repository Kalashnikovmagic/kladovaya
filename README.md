# Кладовая 3.0

Новая версия личного PWA для списка покупок и ручного контроля домашних запасов.

## Основные разделы

- **Покупки** — один общий список, автоматически сгруппированный по категориям. Есть быстрое добавление, подсказки из каталога, количество и комментарии. Купленные позиции остаются в сворачиваемом блоке «Куплено».
- **Запасы** — только товары с включённым отслеживанием. Кнопка «Заканчивается» добавляет товар в покупки; повторное нажатие возвращает статус «Есть» и убирает незавершённую позицию из списка.
- **Каталог** — единая база товаров, поиск, избранное, недавно добавленные и часто покупаемые позиции.
- **Настройки** — системная/светлая/тёмная тема, экспорт и импорт резервной копии, сброс данных.

## Хранение данных

Данные хранятся локально в браузере устройства в ключе `kladovaya:v3`. Серверной синхронизации и уведомлений нет. Резервные копии экспортируются в JSON.

При первом запуске версии 3.0.1 данные из `kladovaya:v2` переносятся в новую структуру: каталог товаров и незавершённый список покупок. Старый ключ не удаляется. Перенос выполняется один раз; уже созданные в новой версии товары и покупки сохраняются, совпадающие позиции не дублируются.

## Разработка

Приложение использует чистые HTML, CSS и JavaScript без сборки. Service Worker обеспечивает офлайн-кэш и показывает пользователю кнопку обновления, когда новая версия готова к активации.

Перед публикацией проверьте основные сценарии на реальном iPhone и в Safari:
1. Добавление нового товара и повторное добавление существующего.
2. Включение отслеживания, перевод товара в «Заканчивается» и обратное переключение.
3. Отметка покупки и отмена отметки.
4. Сохранение/восстановление JSON-копии.
5. Установка PWA и обновление Service Worker.
