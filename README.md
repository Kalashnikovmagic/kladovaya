# Кладовая — меню, закупки и контроль трат на еду

PWA-приложение, чтобы закупаться 3–4 раза в месяц по плану и не тратить деньги на спонтанные доставки.

**Цикл:** блюда → меню на период → автоматический список покупок → закупка → запасы → контроль трат.

- **Меню** — раскладываешь свои блюда по дням (завтрак, обед, перекус, ужин). Один типичный день можно скопировать на все пустые дни периода. Видны ккал, белок и примерная стоимость дня.
- **Список** — «Собрать список покупок» суммирует ингредиенты всего меню, вычитает то, что уже есть дома, и округляет до упаковок. Список разделён на «Долгого хранения» и «Свежее».
- **Продукты** — каталог с фасовкой, ценой за упаковку, запасом, минимумом и сроком годности. Кнопка «Съели» в меню списывает продукты из запасов.
- **Блюда** — рецепты с граммовками на порцию, КБЖУ и себестоимостью порции.
- **Траты** — бюджет на месяц, траты по плану и вне плана (доставка, кафе, перекусы), счётчик дней без доставки, сравнение с прошлым месяцем.

Данные хранятся только на устройстве (localStorage); резервная копия — меню «⋯». Без сборки и зависимостей, хостинг — GitHub Pages.

При изменении файлов увеличьте `CACHE` в `sw.js`, чтобы у пользователей обновился офлайн-кэш.
