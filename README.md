# Кладовая — продукты и закупки

PWA-приложение для дома: список покупок, запасы со сроками годности, каталог продуктов с ценами и история закупок с расходами по категориям.

- Работает офлайн, ставится на телефон как приложение («Добавить на главный экран»).
- Данные хранятся только на устройстве (localStorage). Резервная копия — меню «⋯».
- Без сборки и зависимостей: чистые HTML/CSS/JS, хостинг — GitHub Pages.

## Как пользоваться

1. **Продукты** — каталог: категория, единица, цена, минимальный запас, срок годности.
2. **Список** — добавляйте товары, отмечайте купленное, вписывайте цену, жмите «Завершить закупку».
3. Закупка попадает в **Закупки** (история и траты за месяц), а купленное — в **Запасы**.
4. Если запас ниже минимума, продукт появляется в блоке «Заканчивается» над списком.

При изменении файлов увеличьте `CACHE` в `sw.js`, чтобы у пользователей обновился офлайн-кэш.
